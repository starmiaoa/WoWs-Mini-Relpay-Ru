============================================================
  WoWs-Mini-Relpay-Ru — 俄服《战舰世界》小地图回放渲染工具
============================================================

【下载与启动】
GitHub Releases 提供三种 Windows 版本：
- Windows 安装包（推荐）：WoWs-Mini-Relpay-Ru-Setup-win64.exe
  双击安装即可，自动创建开始菜单与桌面快捷方式。
- 免安装绿色便携包：WoWs-Mini-Relpay-Ru-win64.7z / WoWs-Mini-Relpay-Ru-win64.zip
  请先将整个压缩包解压到任意文件夹（不要直接在压缩软件里双击），
  再双击运行 WoWs-Mini-Relpay-Ru.exe 打开图形界面。

【使用步骤】
1. 打开后程序会自动识别本机的俄服正式服与 PT 测试服目录，并列出 replays
   目录下的全部 .korablireplay 回放文件（如未找到，点击右上角「选择目录」
   手动指定即可）。
2. 首次打开时，程序会在后台自动从本地客户端提取一次地图、官方图标与汉化
   mod 词库（约 3~5 秒），之后无需重复等待。
3. 勾选要渲染的对局，或直接将任意 .korablireplay 文件拖入窗口自动添加勾选。
4. 在右侧选择导出参数后点击「开始生成」：
   - 分辨率：16:9 标准预设，支持 720p / 1K (1920×1080，默认) / 2K / 4K；
   - 帧率：默认 25fps（可选 25 / 30 / 60 fps，与播放倍速解耦，调高仅提升
     画面流畅度，不会加快战局进度）；
   - 播放倍速：默认对齐原项目 20× 战局倍速，可在顶部「设置」标签页按需调整
     0.5×（慢 2 倍）至 4×（快 4 倍）。
5. 每次生成都会按当前时间在 output 目录下创建独立文件夹并自动打开。

【游戏 / 汉化 mod / 软件更新】
- 俄服大版本更新后：切到「设置」→ 点击「重新同步当前客户端数据」（几秒完成）；
- 仅更新汉化 mod 船名时：切到「设置」→ 点击「仅更新汉化词库」（约 1 秒）；
- 软件本身有新版本时：切到「关于」→ 点击「检查更新」，发现新版后点击
  「快速拉取更新」即可自动下载并应用最新 GitHub Release（保留本地 data/ 缓存
  与 output/ 视频）。
